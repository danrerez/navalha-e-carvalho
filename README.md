# Navalha & Carvalho

Site institucional de uma barbearia clássica e rústica (marca fictícia), feito como projeto acadêmico.

- HTML, CSS e JavaScript puro, sem build
- GSAP + ScrollTrigger para animações e Lenis para rolagem suave (via CDN)
- Layout mobile-first e responsivo
- Hospedado na Vercel

## Rodar localmente

Abra o `index.html` no navegador ou sirva a pasta com qualquer servidor estático:

```bash
npx serve .
```

Fotos: [Unsplash](https://unsplash.com).
